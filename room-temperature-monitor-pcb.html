05 PCB DESIGN

Room Temperature Monitor PCB

01Highlights

  • Custom thermometer-shaped Altium board for an Arduino Nano monitor, driving three threshold LEDs from an LM34AH sensor.
  • Thermally isolated the sensor with separate ground pours under the Nano and the LM34, joined by a copper-free neck, so the board’s own heat can’t skew readings.

02Why Altium

I’ve done all my PCBs in KiCad, so I wanted a project in Altium to become more proficient with it. After creating the project files, I used MPN search for every component, a useful tool KiCad doesn’t have. This is a well-known beginner project, so the schematic wasn’t hard to work out.

03Schematic

A lot of errors came up when I thought the schematic was fine. Most went away after renaming some nets and double-checking label connections. The last warning was a pin type error on pin 2 of the sensor; I changed the pin type to passive, which matches how it’s wired, and that fixed it.

04Layout

I imported a JLCPCB rule set from a GitHub repo into Altium, then changed the board shape. One LED was bigger than the others, so I changed the LED models to match widths. The imported footprints acted strangely, with two LEDs far off the board, but a few shortcuts brought them back.

There are two ground pours: one on the rectangular body and one on the round tip. I left the neck without a pour so heat from the Nano and other parts doesn’t travel down to the temperature sensor, which makes the readings more accurate. A single trace ties the two grounds together from the sensor. After wiring, validation showed no errors, and I generated the Gerber files and put them on GitHub.
