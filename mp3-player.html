02System architecture

03Overview

A handheld music player built from a microcontroller, an MP3 decoder module, an OLED display, and physical buttons. The display has a two-level album and track menu, an animated UI, and full playback controls.

The goal was a portable MP3 player that reads MP3 files from an SD card, with controls that make the screen easy to navigate. It was supposed to run on an Arduino Nano, but I switched to an ESP32 because the OLED was using a lot of memory. For the final model, I moved the build onto perfboard to make it permanent.

04Final hardware

  • ESP32 DOIT DevKit V1: microcontroller
  • DFPlayer Mini (MP3-TF-16P): MP3 decoder and SD card playback
  • SSD1306 128×64 OLED: display (I2C)
  • MAX4410 headphone amplifier: drives the earphones, with a volume knob and audio jack
  • 4 push buttons: navigation and control
  • 9 V rechargeable battery and buck converter: powers everything, stepped down to 5 V
  • On/off switch: on the battery’s positive line
  • A decoupling capacitor to reduce static noise in the earphones

05Issues and solutions

Fried the DFPlayer Mini (9 V on a 5 V module)

I connected a 9 V battery without thinking, everything stopped working, and the DFPlayer started to overheat. Thankfully the microcontroller wasn’t harmed. I added a buck converter to step the voltage down and checked it with a multimeter.

Audio playing, but no sound or very poor quality

The module said it was playing, but nothing came out. The DFPlayer Mini doesn’t have a headphone amp, so I bought a MAX4410 headphone amplifier, which fixed it. I also added a decoupling capacitor close to the DFPlayer to reduce noise further.

OLED and DFPlayer wouldn’t work together

One would start while the other wouldn’t, or one would crash. New code didn’t help, so I switched microcontrollers, and that worked perfectly.

Albums played in the wrong order, or not at all

I had named the folders after the albums, but the DFPlayer requires specific naming, so I renamed them 01, 02, and so on. I then changed the code so the OLED shows the real album names instead of the numbers.

A button that never responded

One button never registered, even though the others worked. Continuity mode on my multimeter showed no connection. I suspected the microcontroller, but both boards failed the same way, so the common factor was the breadboard. Moving the button to a different row and GPIO fixed it.

06What I learned

Integrating code incrementally made errors easy to localize, and keeping my basic test sketches told me whether a fault was in the code or the wiring. I also got much better at diagnosing problems with a multimeter. One thing to improve is housing: I’d forgotten a lot of my SolidWorks skills and used an Altoids tin, which turned out sloppy. The perfboard migration went well, but the 9 V battery, amp module, and switch couldn’t fit on it, so the build is still bulky.

Author’s note: after testing every component with basic sketches, I developed the more complex code (the track menu, the animated UI, and tying the playback controls to the display) with Claude Opus 4.8. The hardware choices, wiring, and physical testing were all mine.

07Mini guide

Features

  • Two-level menu: browse by album, then by track
  • Animated boot screen
  • Playing screen with play, pause, skip, a background animation, and a progress bar
  • Double-press to skip forward or go back
  • Auto-advance to the next song

Wiring

DFPlayer Mini (hardware Serial2)

  • VCC → VIN (5 V)
  • GND → GND
  • RX → GPIO17
  • TX → GPIO16

Add a ~500 µF capacitor between VCC and GND to reduce noise.

OLED (I2C)

  • SDA → GPIO21
  • SCL → GPIO22
  • VCC → 3.3 V
  • GND → GND

Buttons

  • Up → GPIO25
  • Down → GPIO26
  • Select → GPIO27
  • Back → GPIO14

Audio output

DFPlayer DAC_L / DAC_R / GND → MAX4410 amp input → earphones (or a panel jack).

Power

The device runs from a 9 V rechargeable battery stepped down to 5 V by a buck converter. That 5 V rail powers the ESP32 (through VIN), the DFPlayer, and the amplifier, and the ESP32’s onboard regulator supplies 3.3 V to the OLED.

SD card setup

Format the microSD card as FAT32. Name each album folder 01, 02, and so on, and name the songs inside 001.mp3, 002.mp3, and so on. Then update the album names, track counts, and track names at the top of the sketch to match your music:

const char* albumNames[] = { "Laufey", "The Strokes" };
const int trackCounts[] = { 8, 4 };
const char* laufeyTracks[] = { "Fragile", "From The Start", /* ... */ };
const char* strokesTracks[] = { "Threat of Joy", "Is This It", /* ... */ };

Libraries

Install these through the Arduino Library Manager: DFRobotDFPlayerMini, Adafruit GFX Library, and Adafruit SSD1306.
